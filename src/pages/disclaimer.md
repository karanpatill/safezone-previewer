## Measurements are references, not guarantees

The margins SafeZoneSnap uses are either reference measurements taken from each platform’s current player layout or values from guidance the platform has published. Platforms change their interfaces with app updates and test layout variants on different groups of users. The space their interface takes up also depends on device shape, operating system, interface language, accessibility text size, caption length and optional elements such as shop links or collaboration handles.

For these reasons, no safe zone, ours included, can guarantee that content will never be covered. Treat every value as a minimum, leave a buffer where you can, and check business-critical work in the platform’s own app before you publish it or launch a paid campaign.

## Simulated interfaces

The interface drawn over your media is a simplified illustration created by SafeZoneSnap to show the position and size of each platform’s controls. It is not a screenshot and does not reproduce any platform’s proprietary artwork, icons or fonts. Counts, handles and caption text in the simulation are examples.
